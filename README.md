# Lucernel plugins

Plugins by Lucernel LLC for Claude (claude.ai, Claude Desktop, Cowork and Claude Code).

| Plugin | What it does |
| --- | --- |
| [musael](./musael) | Plan novels and stories in Musael from ChatGPT or Claude: start a project from an idea, add acts, chapters and scenes, save characters and places to its World, and, where the account includes it, read the manuscript, check a chapter and suggest edits the writer reviews. |

In Claude Code:

    /plugin marketplace add Lucernel/musael-plugin
    /plugin install musael@lucernel

The plugin connects to the Musael server at https://app.musael.com/api/mcp; the writer signs in to their own Musael account the first time. Help: https://musael.com/help/connect-chatgpt-and-claude · Privacy: https://musael.com/privacy · Support: support@musael.com
